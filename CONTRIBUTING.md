# Contributing

1. Create a focused branch and keep public API changes backward compatible.
2. Run `npm run check` before opening a pull request.
3. Add calculation tests for indicator/scale changes and document new public props.
4. Use Conventional Commit prefixes (`feat:`, `fix:`, `docs:`, `perf:`).

The project targets React 18+, strict TypeScript, and evergreen browsers. Avoid adding runtime dependencies unless they produce a measurable benefit.
